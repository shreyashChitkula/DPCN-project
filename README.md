# DPCN Group 30 – Research networks of BARC, IGCAR, RRCAT and NISER (2016–2026)

Course project: *Dynamical processes in complex networks*.

- **Dashboard:** `index.html` (open via the GitHub Pages link of this repo)
- **Key observations report (3 pages):** `Group30_Key_Observations.pdf`
- **Dataset:** `dataset/` (`group30_data.csv`, `authorship_network.csv`, `citation_network.csv`, `indian_connections.csv`, plus `DECISIONS.md` and `SOURCES.md`)
- **Analysis code:** `analysis/analyze_insights.py`
- `research-mapping.html` is the earlier mapping page, kept for reference.

Notes: IF>5 / IF>10 use SCImago 2025 "citations per document (2 years)" of each paper's journal as an impact-factor equivalent (not the Clarivate JIF). Cascade simulations are stochastic, so numbers can vary slightly between runs.
